# Plan Mode (Strict)

Plan mode is for **meticulous planning and analysis with implementation fully disabled.** Use it ONLY for skills that produce a plan, design, or proposal and write nothing — no code, no files, no external resources. A skill that creates or modifies anything (even after approval) does NOT belong in plan mode — use the `present-first` reference instead.

> **ALWAYS enter plan mode when this prompt is invoked.**
>
> - Enter plan mode immediately.
> - **Implementation is disabled for the entire skill.** Do NOT write code, create files, or modify any external system.
> - **NEVER exit plan mode** until the user gives an explicit, unambiguous implement signal ("implement this", "start coding", "write the code", or the lingo `g` / `go` / `y` / `yolo`).
> - When unsure whether the user wants implementation, ASK. When in doubt, STAY in plan mode.
> - Produce the plan/analysis, present it, and wait for direction. You are a planner, not an implementer.
